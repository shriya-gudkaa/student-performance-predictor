# KNN Student Performance Predictor

This project predicts whether a student will pass or fail using the K-Nearest Neighbors (KNN) algorithm.

## Features
- Data preprocessing using pandas and NumPy
- Pass/Fail classification based on marks
- KNN model using scikit-learn
- Feature scaling using StandardScaler
- Model evaluation using accuracy score

## Dataset

The dataset used in this project is taken from Kaggle.

- Source: Kaggle Student Marks Dataset  
- It contains student details and marks in multiple subjects.

## Technologies Used
- Python
- pandas
- NumPy
- scikit-learn
- matplotlib
